# Load-Adaptive Non-Orthogonal Signature Masks — Reproducibility Package

Code, raw results, and figures for the manuscript *"Load-Adaptive
Non-Orthogonal Signature Masks for Multi-User Semantic Communications"*
(submitted to IEEE Transactions on Signal Processing, September 2026).

Mask-based superposition of Swin-transformer image embeddings with
variable-load training, compared against re-encoded orthogonal multiple
access (OMA), a deep multiple-access design with one transceiver pair per
user (DeepMA), and a token-signature reference (ToDMA-style, genie-aided
association) on Rayleigh block-fading channels at a fixed channel
bandwidth ratio. Beyond the provisioned population the schemes are compared
by a classifier-based semantic throughput.

## Layout

- `code/` every script (training, evaluation, plotting) and the `swinsc/`
  package (transmitter, receiver, mask multiplexer, Swin blocks, channel)
- `data/` raw results as CSV, one file per experiment; figures never embed
  numbers directly
- `fig/` the figure PDFs, regenerated by `code/plot_results.py` from
  `data/` alone

## Requirements

- Python >= 3.12, PyTorch >= 2.10 (CUDA build), torchvision, pillow,
  pyarrow, matplotlib
- One GPU with >= 12 GB memory (results produced on an NVIDIA RTX A4500,
  PyTorch 2.11 + cu130; `--accum N` splits a batch into N steps on a
  shared or smaller GPU without changing the effective batch)
- Dataset: Imagenette-160, downloaded by `code/prepare_imagenette.py`

`code/config_main.py` holds the single main configuration (L = 8, l_s = 8,
beta = 1; dimension-rich variant l_s = 16, beta = 2) and the workspace
root (`SWINSC_ROOT`, default: the repository root).

## Reproducing the results

All randomness is seeded (`seed = 0` for models, `2026` for the token
signatures). One script per experiment; the plot script reads only `data/`.

```bash
python code/prepare_imagenette.py                    # dataset -> data/imagenette160

# --- training (one model per call; 30-60 min each on an A4500) ---
python code/swin_train.py --dataset imagenette --img_size 128 --users 4 \
    --mask learned --l_s 8 --beta 1 --channel rayleigh --epochs 20 --amp --bs 24 \
    --out checkpoints/swinsc_ov_u4_learned
#   repeat per the model table below (--users, --mask, --var_load)
python code/todma_train.py --l_s 8 --v 256 --epochs 15  # token-signature VQ autoencoder

# --- evaluation (each writes its own CSV under data/) ---
python code/tsp_eval.py                                  # PSNR grid, N = 2, 4 -> data/tsp_eval.csv
python code/tsp_eval2.py                                 # N = 2 variable-load and L = 32 set -> tsp_eval2_raw.csv
python code/tsp_eval3.py --offload                       # N = 6, 8 sweep and off-load rows -> tsp_eval3_raw.csv
python code/merge_eval.py                                # merges the raw files into data/tsp_eval.csv
python code/ser_eval.py   --out data/ser_eval.csv        # PSNR + semantic error rate, K = 1..8
#   (--wh_only evaluates just the dynamic Walsh-Hadamard OMA chain, which
#    reuses the swinsc_ov_u{1,2,4,8}_oma heads through an 8-code pool)
python code/ssim_eval.py  --out data/ssim_eval.csv       # SSIM at 10 dB, N = 4
python code/dump_artifacts.py                            # masks.csv, mux_weights.csv, param_counts.csv
python code/sinr_model.py                                # data/sinr_model.csv from masks.csv
python code/sinr_mc_check.py                             # Monte Carlo check of the SINR model
python code/gamma_concentration.py                       # data/gamma_concentration.csv
python code/todma_coherence.py                           # signature-dictionary coherence

# --- figures (reads only data/, writes fig/*.pdf) ---
python code/plot_results.py
```

## Model table (flag sets)

| Checkpoint | Flags |
|---|---|
| `swinsc_ov_u{2,4,6,8}_learned` | `--users N --mask learned` (fixed full load, one per N) |
| `swinsc_ov_u{1,2,4,8}_oma` | `--users N --mask oma` (re-encoded OMA, B = 8/N) |
| `swinsc_ov_u{2,4,6,8}_deepma` | `--users N --mask deepma` (one encoder-decoder pair per user) |
| `swinsc_ov_u{2,4}var_learned` | `--users N --mask learned --var_load` (variable-load model) |
| `swinsc_ov_u8var_learned` | `--users 8 --mask learned --var_load` (single model with eight masks) |
| `todma_v256` | `todma_train.py --l_s 8 --v 256` |
| dimension-rich set | `--users 2 --mask learned/oma/deepma --l_s 16 --beta 2` (+ `--var_load`) |

All runs share: Imagenette 128x128 crops, Rayleigh block fading with
perfect-CSI zero forcing, training SNR Uniform[0, 20] dB, AdamW 3e-4 with
cosine decay and weight decay 1e-4, gradient clipping 1.0, bf16 autocast,
batch 24 per user, 20 epochs, seed 0.

All figures are produced by `code/plot_results.py`. Tables in the paper
quote `data/tsp_eval.csv` (PSNR), `data/ser_eval.csv` (SER, throughput),
`data/ssim_eval.csv` (SSIM), `data/param_counts.csv` (parameter counts),
`data/masks.csv` / `data/mux_weights.csv` (mask statistics),
`data/sinr_mc_check.csv` (Monte Carlo agreement of the SINR model), and
`data/gamma_concentration.csv` (appendix concentration check).

`data/tsp_eval.csv` columns: `scheme, designed, active, snr, psnr` (mean
per-user PSNR in dB over 200 validation images per user per point).
`data/ser_eval.csv` adds `ser`, the fraction of delivered images whose
ResNet-50 (ImageNet weights, logits restricted to the ten Imagenette
classes) prediction differs from the label; the `clean` row is the
classifier's error on the source crops.

## Conventions

- CBR = complex channel symbols / source values = L/96 for the 2-stage
  encoder (token = 4x4 pixels = 48 values, L real dimensions per token).
- Frame power is normalized to 1 over the ACTIVE users; the noise variance
  per real dimension is 1/SNR; the Rayleigh gain is constant per frame and
  zero-forced at the receiver.
- Semantic throughput T(K) = sum over served users of (1 - SER). A scheme
  provisioned for N users serves min(K, N); static OMA and DeepMA rows for
  K > N therefore repeat their K = N value.
- The receiver's per-user `reduce` projection is a plain linear layer (an
  earlier LayerNorm there destroyed the information of narrow OMA blocks;
  every checkpoint in this package was trained after its removal).
- Token signatures follow Qiao et al. (IEEE INFOCOM WKSHPS 2025): fixed
  random Gaussian signatures per vocabulary entry, OMP support recovery,
  genie-aided association (an upper bound on any practical association).
